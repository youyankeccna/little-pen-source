手机打印

  1. 保存 PDF 后，在“文件”或“下载”中打开。
  2. 苹果手机：从共享菜单选择“打印”，需要支持 AirPrint 的打印机，并与手机连接同一 Wi-Fi。安卓手机：使用 PDF 阅读器的打印菜单或打印机品牌应用。
  3. 按打印机说明连接网络。找不到设备时，可以把 PDF 发到电脑再打印。

在微信内打不开下载或打印时，用系统浏览器打开本网站后重试。不同设备的菜单名称可能不同。苹果打印说明 · 安卓打印说明

电脑 / 打印店

  1. 电脑可直接打印，也可用 PDF 阅读器打开文件。
  2. 选择 A4、纵向、“实际大小”或 100%。网页直接打印时关闭页眉页脚、选择无页边距。
  3. 先试印一页，对照预览检查格子大小和裁边，再打印剩余页。
省墨、铺满 A4 与多页下载

“铺满 A4”会重复练习内容补满纸张，按孩子的练习量选择，不必每次开启。省墨灰度会淡化格线和描红；请先试印确认能看清。

每次支持 1–20 页。PDF 合并全部页面；PNG 按页下载，多页时浏览器可能需要允许多个下载。
