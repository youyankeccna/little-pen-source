# Z2H 功能与内容拆解 / 复刻对照

核对日期：2026-10-14。参考站：https://z2h.cn/ 。

本轮目标是先复刻参考站的功能和内容组织，暂停第一版的分年龄、推荐素材与练习计划方向。网页保持独立在 `web-preview`，不修改 uni-app 小程序。

## 1. 内容结构：十个独立入口

| 参考页面 | 输入和排版方式 | 本版 |
| --- | --- | --- |
| `/hanzi` 汉字 | 一个汉字一行，按格子重复练习；连续空行可保留留白 | 已实现 |
| `/cizu` 词组 | 空格、逗号、换行分隔词组，一个词组一行，按词组重复 | 已实现 |
| `/duanluo` 中文段落 | 段落连续排版；横线格按宽度折行，其他方格按列数折行 | 已实现；标点处理需进一步与原站校准 |
| `/bihua` 笔画 | 默认五个空输入行，选择笔画、填写例字，增删行；例字排在行尾 | 已实现编辑功能；58 个条目使用独立线条图形 |
| `/alphabet` 英文字母 | 一个字母一行，可自动生成大小写成对形式 | 已实现 |
| `/word` 英文单词 | 逗号或换行分隔单词，重复按文本实际宽度排列 | 已实现；字距受替代字体影响 |
| `/paragraph` 英文段落 | 连续文章按词换行，保留段落 | 已实现；极长单词也不会丢失 |
| `/number` 数字 | 每行一个数字或一组数字，重复练习，可插入空列 | 已实现；原站数字专用字体不同 |
| `/pinyin` 拼音 | 每行一组拼音，支持声调韵母快捷输入和四线格 | 已实现；快捷键包含 30 个基础字母与带调字母 |
| `/pen-control` 控笔 | 1—9、A—W 共 32 个形状，点击追加，按行重复 | 已实现数量和选择方式；采用独立绘制图案 |

十类默认内容分别保存；刷新、切换页面后恢复浏览器内的设置。输入弹窗支持 20,000 字符，控笔输入上限 100 个形状。为适配静态服务器，路由采用 `#/hanzi` 等 hash 路由。

## 3. 纸张和参数

- 参考站采用 A4 比例画布（791.8 × 1118.66 CSS px），一页会铺满格线，内容写完后的行保持空白。本版沿用这个布局尺寸，导出设为标准 A4（210 × 297 mm）。
- 页边距默认上下左右均为 36 px，分别可调。格子大小或行高默认 10 mm，行间距默认 2 mm；控笔默认 0 mm。
- 七种中文格：作文格、田字格、米字格、回宫格、九宫格、回田格、回米格。
- 中文段落增加横线格；英文单词和段落支持四线格、两线格、单线格。
- 中文字体大小默认 68%，英文 / 数字默认 85%，拼音默认 60%；大小范围 48%—128%。
- 上下偏移范围 -50%—50%，一般默认 0%；数字默认 20%，拼音默认 -12%。
- 字体粗细为常规 / 加粗。控笔粗细同样支持两档。
- 描红数量默认 20，笔画默认 5；段落无此设置。数量为重复组数，最多受行宽限制。
- 描红颜色默认 `#94a3b8`，格线颜色默认 `#64748b`，可自由选择。
- 中文横线段落字间距范围 -10—10 px。
- 自动分页；预览按可见页绘制，避免长内容同时占满画布内存。导出会处理全部页面。

## 4. 编辑与导出交互

1. 点击右侧输入区，打开输入弹窗；取消不提交，确定后重新排版。
2. 拼音输入弹窗提供带声调字母，插入当前光标处。
3. 笔画弹窗提供选择条目、例字输入、添加、移除、取消和确定。
4. 修改开关、滑块、颜色及字体后更新预览。
5. 导出菜单分为 PDF / PNG：PDF 合并多页，PNG 按页下载。
6. 打印使用独立 iframe，包含字帖页面，不含网页导航和设置。
7. 各类型的配置存储在浏览器 localStorage，互不覆盖。
8. 汉字 / 词组自动标拼音，并可按整行校正；校正值同时应用于预览和导出。
9. 汉字笔顺按笔画累积显示，当前笔画为红色，前序笔画为黑色。未收录时明确提示。

本版的 PDF / PNG 与预览使用同一绘制函数和配置快照。PDF 为栅格图像型，与参考站的图像导出方式相同，不是可检索文字型 PDF。

## 5. 尚未完全一致的项目

| 项目 | 差异与后续工作 |
| --- | --- |
| 完整字体库 | 原站有多种中文、英文、数字和专用拼音字体。本版提供系统字体、随网页提供的开源字体，以及本地字体文件导入；尚未完整复制原字体库。 |
| 控笔字形 | 数量和交互为 32 种，但图案由独立代码绘制；个别图形与原站专用字体的线条与造型不同。 |
| 笔画字形 | 58 个选择条目已覆盖，使用独立示意路径；并非原站书法笔画字体。例字使用自选常用字，未整套照搬原站例字库。 |
| 拼音选择方式 | 原站汉字多音字在纸张旁选择。本版集中在“校正拼音 / 多音字”弹窗输入，也支持词组上下文。 |
| 排版细节 | 字体字宽、字母/拼音/数字间距、段落标点挤压与回宫格比例，需要继续对照校准；不能宣称像素或输出完全一致。 |
| 站点外围 | 保留自己的名称与说明；未复制第三方捐助收款、备案号、商标、统计脚本。 |

本版不宣称已经 100% 一比一。后续优先补齐完整字体选择，再校准字形和间距；这之前不扩展分年龄、课程同步或打卡需求。
