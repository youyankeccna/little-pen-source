## API v1请求约定

JSON成功形状为`{data,requestId}`，错误为`{error:{code,message},requestId}`。二进制输出例外。写请求需与服务配置匹配的Origin，浏览器使用HttpOnly Cookie。接口清单 server/openapi.json。

偏好请求：`PUT /api/v1/me/preferences`，body为`{"preferences":{"cn":"pep","math":"pep","en":"pep"},"version":0}`；读取/me获取当前preferenceVersion，冲突409必须刷新后重新操作。

快照请求：`POST /api/v1/worksheet-snapshots`，body含sourceMode（lesson或custom）、type、pages、config。课内增加lessonId、practiceKind、itemIds、contentVersion；服务器以发布清单核对课次与文字，禁止伪造跨课内容。config沿用当前引擎的白名单字段，拒绝任意资源URL或路径。返回私有snapshot.id，读取仅创建账号可用。

输出请求：`POST /api/v1/outputs`，Content-Type为application/pdf或image/png，并携带`X-Worksheet-Snapshot: <id>`。未登录401、偏好未确认409、非本人快照403。旧/api输出别名执行相同权限，不是匿名旁路。

改密：`PUT /api/v1/auth/password`，body含password和newPassword；成功后全部会话失效。注销：`DELETE /api/v1/me`，body含password及confirmation“注销账号”。这两个入口通过页面表单由账号本人操作。
