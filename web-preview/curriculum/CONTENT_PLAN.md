# 按课次选择内容：第一版

主流程：年级 → 学科 → 册次 → 单元／课题 → 字、词、句段等内容 → 勾选 → 预览 → 打印／下载。自主练字保留为次要入口。

## 当前内容范围

当前发布826条课题／活动（含幼儿园6项），32个小学年级×学科×册次组合有补充练习；其中356条仅课题选字词。目录总数与教材完整率尚未核验，不能按“非空”推算完整率。英语保留官方当前配套7册49条目录，六年级下册为单独标注的历史参考。当前没有声称完整教材同步。服务端出版清单与覆盖报告由 `node scripts/content_release.cjs` 同步生成；`--check` 可核对是否过期。

v12选编样本覆盖一年级上册24课题及一下、二上、二下各12课题，共60课题（含拼音及一首公版古诗）；二批新增36课题的字词和自编短句。这些不作为教材完整字词表，不代表版次、单元或教学审核完成。

内容按来源标为自编巩固、公版古诗原作或诗中选字词。自编内容不能当作教材写字表、词汇表、课文原文或原题；古诗采用独立原作版本，不能直接视为教材编辑版本。幼儿园活动不是人教教材课次。未录入的册次和未补齐内容显示状态，不能生成替代的其他年级内容。

## 后续正式内容录入

每册先固定教材系列、出版年份、修订版次、ISBN、学期和目录来源，再逐课核对课号、标题、页码、写字表、词语表和可使用句段。英文需区分 PEP 三年级起点和其他系列；数学按教材实际单元与小节录入，避免虚构课次。内容经过审核后才标为教材内容，段落需有可使用依据。

数据字段位于 data.js：lesson 的 grade / subject / term / unit / title / edition / source / catalogStatus；pack 的 kind / origin / items。自编补充和教材内容始终分别展示。

## 审核导入

`node scripts/review_content.cjs <review.json>` 只校验并显示差异；追加 `--publish` 发布审核记录。输入为数组，每条指定现有lesson id及status（draft、approved、withdrawn）。approved必须有title、source（HTTP或HTTPS）、reviewer、reviewedAt（YYYY-MM-DD）、rightsBasis和packs；内容项必须提供明确且唯一的id及text。草稿仅存server/content-review.json，不进入公开脚本。批准记录只代表输入的人工审核记录，工具不代替教学、来源或权利核查。

变更后运行发布清单生成器，并重启服务以使前端与API生效版本一致。server/content-archive按内容哈希留档；撤回用withdrawn，已有账号快照保留当时文字。恢复旧发布清单时还需恢复匹配的前端审核脚本及代码，不能只替换一个JSON就声称整站回滚。旧条目保留兼容ID，新导入内容不得重新按数组位置分配ID。
