# 小小笔尖：书写工坊

当前界面使用顶部导航、白底灰绿背景和统一控件。选课与账号教材设置分开；支持多孩子独立练习、每日安排、分日练习包及成长记录。现有十类字帖与 A4 排版继续可用。

新版入口：http://127.0.0.1:5178/?v=36#/ 。游客可预览、直接打印及导出 PDF／PNG；登录后可云端收藏与同步学习设置；级联下拉选课和账号教材偏好已接入。架构与部署边界见 [ARCHITECTURE.md](ARCHITECTURE.md)。

设计对照见 [design-qa.md](design-qa.md)。

原有功能基线对照 https://z2h.cn/ 的十类字帖、参数编辑与导出流程。网页前台与账号API使用同源服务，不修改现有 uni-app 页面。

## 现在怎么使用

1. 第一次：设置学习信息 → 进入整册素材库（默认选一页，可调整）→ 预览 → 直接打印／下载。语文无需选单元或课次，英语选单元，数学选计算专项；原按课次入口保留。
2. 再次进入：点击首页“打开今日练习”或“继续练这课”，直接进入已准备的练习纸。需要换内容时才点“选新内容，练一页”；其他练习入口在“更多练习与管理”中。
3. 每周安排：已有练习包直接重开，点击“重新安排”才新建；同一浏览器保留上次数量、天数等选项。
4. 换教材／升年级：点击“修改学习信息”；切换孩子后自动显示该孩子的设置与进度。

账号保存学习设置、课次、字帖与练习包；未保存的排版和游客记录保存在当前浏览器。需要跨设备保留完整排版，请“保存并收藏”，以后从“我的字帖”打开。

## v27 账号密码找回（2026-10-24）

登录窗口新增“忘记密码”，使用账号、恢复码及两次新密码重设。注册成功时显示一次恢复码，可下载文本；现有账号在“账号安全”验证当前密码后生成／替换。恢复码只保存 SHA-256 摘要，随机 128 位，不进入 URL 或浏览器存储；使用、重新生成或修改密码会使旧码失效。重设在事务内校验并消费恢复码，撤销全部会话，不自动登录，不删除孩子或字帖。

没有预先保存恢复码、且已忘记密码的旧账号，不能仅凭账号自助找回：管理员须先核验账号所有者，再用 `python3 scripts/issue_recovery_code.py --database /path/accounts.sqlite3 --username 账号 --to /private/new-recovery.txt` 生成一次性恢复文件。文件必须位于网站静态目录外，权限 0600、拒绝覆盖；工具不输出恢复码，替换旧码并撤销会话。手机／邮箱验证码仍未开通。

接口：`POST /api/v1/auth/recovery-code`、`POST /api/v1/auth/reset-password`。每 IP／每账号十分钟最多十次，未知账号与错误恢复码返回同一提示。数据库自动增加 `users.recovery_hash`，`user_version=7`，旧账号密码与学习数据保留。客户端“我已保存”关闭后清空恢复码显示，注册后再进入原学习信息流程。

验证：21 项后端测试通过，覆盖恢复码摘要、错误码、确认密码、会话撤销、并发单次消费、限流、旧数据库迁移和私有管理员文件；临时数据库浏览器验证注册领取、重设后登录、重新生成、关闭清空及 375px 布局。未对真实账号执行密码重设。

实现参考：[OWASP Forgot Password Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html)。当前限流沿用本地内存机制；正式部署仍需邮件／短信服务及持久化限流。

- 英文字母：52 个大小写字母的本站原创单线书写示例；起点、方向与笔画编号，点线／实线描红，大小写成对、渐隐和 A4 铺满继续可用。可选大小写全组、直线、圆弧、易混字母组。引导开启时隐藏无效的字体调节，关闭后恢复普通字体。这些示例未经教材书写规范审核，请结合任课老师要求选用。
- 控笔：直线与方向、曲线与圆弧、转折与折线、综合小图形四阶段，含起点和箭头；可以自由选阶段，同一浏览器记住当前孩子上次选择。
- 汉字跟写：本地 Hanzi Writer 3.5.0 + 已有笔顺数据，支持整字演示、逐笔观察、沿轮廓跟写、隐藏轮廓独立写和部首着色；鼠标／触摸输入按笔顺提供反馈。只做笔顺交互，不做书写美观评分，也不自动增加打卡记录。未收录字显示提示。
- 打印页眉：可添加标题、姓名、班级、日期，留空打印填写线；设置会进入账号快照。公开课次分享移除自定义标题、姓名、班级和日期。
- 批量姓名：每行一个名字，最多 20 个，每个 1–6 个汉字；每个名字独立起页、自动对应姓名栏，默认铺满 A4。大字号／留白可能让一个名字占多页，每次导出仍最多 20 页。名单仅用于当前浏览器和自己的账号字帖，不提供公开分享。
- 再次使用：启蒙模板各自保存排版，不覆盖自由字帖；收藏后可跨设备从“我的字帖”重开。名单输入框保留当前会话内容，已调整的姓名字帖草稿保存在当前浏览器；账号收藏保存完整名单与版式。

验证：10 组前端测试、14 项后端测试通过；真实浏览器验证跟写正确／错误反馈、关闭重开、手机布局、引导开关、设置刷新、控笔续练与姓名收藏重开；实际导出并逐页查看 2 页姓名、2 页小写字母、1 页控笔 PDF，均为 A4。样例见 `output/playwright/v23-*`。实体打印机和真实手机触摸尚未验证。

引擎发布版本 `workbook-5`。库许可证见 `vendor/licenses/hanzi-writer-MIT.txt`，数据沿用现有 ARPHIC 许可；运行时不请求外部 CDN。素材逐条审校、教材完整度和更多版次覆盖仍是独立待办，详情沿用 v21 内容清单。

## v19 第二、三批功能

- 每日练习：使用当前孩子教材，可选择课次及字词数量；语文字词可加入最多2个到期薄弱字。支持已有素材覆盖的其他年级与英语单词。
- 一周练习包：选择起止课次、5/7天、每日数量及日期；按实际内容生成，预览后可返回调整；保存后下载带日期、家长勾选栏的 A4 PDF。
- 成长记录：家长手动确认完成，累计天数、周历、主题贴纸；完整完成至少5天的每周安排后显示纪念卡。打印和下载不等于完成。
- 孩子档案：账号内最多6个，独立教材、年级、进度、薄弱字、收藏与练习包；原账号资料自动归入默认档案。
- 分享：课次预览页可生成30天分享链接；收件人可预览，登录后另存自己的字帖。账号菜单可停用；不共享姓名练习或成长数据。当前localhost地址仅在本机使用，外部访问需公网部署。
- 幼儿启蒙：控笔线条、基本笔画、数字和名字练习；语文课内可展开“看笔顺 · 书写指导”。笔顺使用已有本地数据，未收录字显示明确提示。
