## 本次实现

“做字帖”页在科目内展示模板，下面保留自由制作入口。

- 语文：拼音描红、笔顺入门、独立临写、词语积累。
- 英语：字母启蒙（大小写成对）、单词描红。
- 控笔：直线控笔（含起点与方向提示）。

模板卡片使用现有字帖引擎绘制前两行缩略预览，笔顺数据在编辑器内加载。所有文字都是示例，不声称对应完整课本。模板只设置当前自主练习，不能覆盖课本、收藏、分享或薄弱字上下文；不修改账号的常用排版偏好。模板载入后保存为当前类型草稿，刷新沿用当前练习；再次点击模板会重新载入模板设置。

没有复制对方模板图片、字体、教材数据或代码。

## 后续顺序与验收条件

1. **姓名字帖快捷入口**：复用已有姓名引擎；个人姓名不进入公开二维码，名单每人独立分页。
2. **偏旁部首与结构学习卡**：数据有来源、许可和抽样核对；未收录项目不猜测。
3. **空白作品纸、作文纸**：按 A4 实际尺寸；格子、标题、署名不跨页；PDF 与浏览器打印均验证。
4. **更完善的模板收藏与历史**：复用账号快照；展示实际排版；游客功能不减少；不同孩子数据隔离。

微信重新打开后继续核查：纸张筛选项、模板编辑细节、生成后的下载选择、收藏/历史恢复规则、姓名与偏旁入口内部流程。上述待核查项不视为已经实现。
