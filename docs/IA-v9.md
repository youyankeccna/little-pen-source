# 信息架构 v9

## 原则
1. **每个科目是独立模块**：语文 / 英语 / 数学 / 控笔各有自己的类型与设置，互不串用（`EditorPanel.isolate`）。
2. **数学只练计算**：取消"数字字帖"(#/number → #/calc)。在计算题的答案格（方格 / 田字格，1–2 年级默认）里写数字，相当于在计算中练字。
3. **跟课本只有一个入口**：#/course，"按课次 / 素材库"两个标签。
4. **任何字帖都能分享**：分享链接和二维码都能复原当前字帖；二维码里内容太长时，改为链接到首页。
