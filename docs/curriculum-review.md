# 统编语文 1–2 年级写字表校对记录

校对日期：2026-11-02，2026-11-03 补充第二轮（America/Los_Angeles）。范围：`web-preview/curriculum/material-bank.js` 中 `bank-cn-1-upper`、`bank-cn-1-lower`、`bank-cn-2-upper`、`bank-cn-2-lower` 的写字表（`characters` 包）。

原则：
- 不编造教材内容。只收录**至少两个独立来源一致**的字。
- 只有一个来源的字、来源之间有冲突的字，都不收录，记在“未解决”里。
- 原 OCR 句子、课文片段、词语表（`sentences` / `chineseTexts` / `words`）没有逐条核对，**页面上不再显示**。原数据保留在 material-bank.js 里，方便以后继续校对。
- 自编巩固内容（`extra*`）和公版古诗照常显示，并标为“自编”。

校对结果保存在 `web-preview/curriculum/reviewed-xiezi.js`。`web-preview/curriculum/review-gate.js` 按这份结果决定页面显示哪些册次。

## 修正的 OCR 错误（举例）

- 1上：OCR 包含“另、办、爪”，不在写字表里，已去掉。OCR 只抓到 51 字，现在用完整的 100 字替换。
- 1下：OCR 里有“舌”、“嘴、饼、址、挐、笪、開、設、釋、殺、單、晏、獎、霍、咒”等识别错误或不属于写字表的字，已全部去掉，换成完整的 200 字。
- 2上：OCR 里有“丑、巽、窪、嗬、勺、匕、照、酱、贺、苣、獈、形、状、弯、窥、窕、今、冰、間、患、單、長、帶”等字，与新版分课表不一致，没有收录。
- 2上 OCR 词语表的明显错误，例如“妈奶”“巴经”“出发动物”“松柏化石开花”。这些是分词或识别错误，整个 OCR 词语包已不再显示。
