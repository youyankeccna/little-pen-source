# 竖式计算

状态：在已交付的口算模板上直接扩展。日期 2026-11-07。

## 范围

口算保留。竖式是同一张计算练习里的另一种排版，不另建数学模块，也不做数字描红。

只使用现有已校对题库里、能够排成竖式的加减乘除。分数、连加连减、混合运算、方程、百分数和比不能排成竖式，页面说明原因，不提供假装能生成的入口。

除法使用除法竖式（商在括号上方，除数在左侧），不把除号上下叠放。

## 纸面

学生页只显示对齐的题干、运算符和横线，并留出进位、借位、过程和答案的位置。答案页用同一批题，写出计算过程和结果。学生页不出现结果。

默认按书写高度排满一页，保留页边距，不把字号缩到口算 28 题的密度。一题不拆到两页。同一页不重复。换一张继续向后取题；题库用尽时说明，不回头重复。

## 兼容

旧的计算链接没有竖式字段，仍是口算。新链接只在竖式时带上排版字段。口算和竖式切换、换一张，都保留年级、专项和答案开关。不新增账号流程。
