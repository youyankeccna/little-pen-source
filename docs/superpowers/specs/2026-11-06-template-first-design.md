# 模板优先：直接选、铺满一页

状态：已批准，按此实施。记录日期 2026-11-06。

## 目标

在现有做字帖入口里，把模板从 26 款扩充到合计至少 40 款。游客选一张就能预览，默认铺满一页可打印区域。自定义输入仍是次要入口。

## 已确认规则

1. 合计至少 40 款，按科目、年级和练习用途区分。每张卡片有真实内容和合理默认排版。不是每科 40 款，也不只改标题凑数。游客选择即可预览，没有必填输入，也不弹出学习信息。
2. 默认铺满一页可打印区域，保留页边距和现有字号、格子毫米尺寸。不靠放大格子或缩小字体来凑满。语文和英语按练习规律重复。计算用不同题目填充：同一页不重复，换一张尽量换题；题库用尽时停止，不循环、不静默重复。控笔图形铺满可打印区域。古诗保留完整诗句和诗文，不截断；放不下一整句时允许少量留白。默认练习正文一页。用户已有的多页选项保留。可选答案纸不算正文第二页。
3. 「换一张」保留年级、题型、字号、格子、描红、答案开关等用户排版，只更换当前模板的内容。切换模板使用该模板自己的默认值，不带上一个学科的内容。恢复默认和换一张是两件不同的事。自定义输入留作次要入口。
4. 只完善现有 `#/make` 模板入口，不另建素材库，不改首页主体、四导航（首页 / 做字帖 / 跟课本 / 我的）、纸与墨，也不改小程序 `src/`。语文、英语、控笔设置各自独立。数学只做计算，入口是 `#/calc`，不做数字描红。保留手机端提示不挡按钮、44px 点按、16px 输入和安全区。教材校对闸门不放开，不导入未校对或他站教材。

## 对标边界

公开页面只用来理解机制：按练习任务列出入口、提供分类预设、预填示例、说明长度和打印。整页铺满是本产品自己的要求。不复制他站源码、素材、付费内容或大段文案，也不把未实测的交互说成已验证。

## 验收

- 模板 ID 唯一，有效总数不少于 40，内容非空、不是占位。
- 游客对每个科目都能不输入就生成样例。
- 不同模板内容或练法确实不同，科目筛选与类型一致。
- 各科默认一页，没有额外空白正文页，没有裁切；最后一行靠近可打印底部；字号、格子和页边距保持稳定。
- 古诗不丢字、不截断诗句。
- 计算题和答案是同一批，同页去重；连续换一张题目不同；题库用尽时停止。
- 换一张保留自定义排版。刷新或切换科目不会串内容。
- 390px 触屏可以点到主要按钮；至少一档小屏没有横向溢出，提示不挡住按钮。
